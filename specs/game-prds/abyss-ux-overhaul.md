## 1. 概述

### 1.1 问题陈述

用户体验深渊后的核心反馈：

| # | 问题 | 严重度 | 现状分析 |
|---|------|--------|---------|
| 1 | **等待时间过长** | 🔴 致命 | 5 层 Boss 战逐回合执行（1 秒/回合），一次完整深渊挑战可能需要 2-5 分钟纯等待，过程枯燥 |
| 2 | **过场缺失** | 🟡 严重 | 层间切换无任何视觉过渡，直接跳到下一层战斗，缺少仪式感和紧张感。Boss 登场无介绍画面 |
| 3 | **稀有装备爆率缺乏刺激** | 🟡 严重 | 当前仅品质 ≥ 4 有翻牌动画，品质 3（稀有）无特殊表现。翻牌动画缺少"赌博感"和惊喜感 |

### 1.2 核心玩家价值

> **深渊 = 刷装备的核心循环。必须做到：进入快、战斗快、爆装爽。**

- ⚡ **快速战斗**：一键跳过战斗过程，直接看结果
- 🎬 **过场仪式**：每层 Boss 登场有专属画面（SVG 占位），制造"即将面对强敌"的紧张感
- 🎰 **老虎机爆装**：稀有以上装备掉落时，全屏老虎机滚动特效 + 庆祝动画

### 1.3 设计原则

1. **SVG 占位优先**：所有美术资源用 SVG 占位，留下清晰的替换说明（`<!-- PLACEHOLDER: 设计师替换说明 -->`）
2. **等待时间 < 5 秒**：快速战斗模式下，从进入到看结果不超过 5 秒
3. **情绪递进**：普通装备 → 简单展示 / 稀有 → 小特效 / 史诗+ → 老虎机全屏

## 2. 功能需求

### FT-01：快速战斗模式

**目标**：将 2-5 分钟的深渊挑战缩短到 3-5 秒。

**交互流程**：

1. 深渊入场界面新增「⚡ 快速战斗」按钮（与现有「进入」并列）
2. 点击后：
   - 扣除入场资源（与正常入场一致）
   - 跳过逐回合战斗动画
   - 服务端逻辑瞬时执行全部 5 层战斗
   - 显示一个 2-3 秒的"战斗进度条"过渡动画（SVG 背景 + 进度条）
   - 战斗结束后直接进入结算界面（复用已有的结算动画流程）
3. 首次挑战某深渊时**不允许快速战斗**（强制看一次完整流程，体验 Boss 剧情）

**进度条过渡画面**：
- 背景：SVG 占位（深渊主题暗色背景 + 战斗剪影）
- 中央显示进度条，文字显示 "第 X/5 层..."（200ms 间隔依次推进）
- 进度条走完后自动进入结算

**验收标准**：

| # | 场景 | 预期 |
|---|------|------|
| A1 | 玩家首次挑战 abyss_hulao | 不显示「快速战斗」按钮，只能正常进入 |
| A2 | 玩家已通关 abyss_hulao，再次进入 | 显示「进入」和「⚡ 快速战斗」两个按钮 |
| A3 | 点击「⚡ 快速战斗」，资源充足 | 扣除资源 → 显示进度过渡（≤ 3 秒）→ 进入结算 |
| A4 | 快速战斗结果为通关 | 结算界面与正常通关完全一致（粒子 + countUp + 装备揭示） |
| A5 | 快速战斗结果为失败 | 结算界面显示止步层数 + 已获奖励 |
| A6 | 连续使用「再次挑战」→「⚡ 快速战斗」 | 流程正常，无残留 DOM 或状态异常 |

### FT-02：层间过场画面

**目标**：在正常战斗模式下，每层 Boss 战前后增加视觉过渡。

**过场类型**：

#### 2a. Boss 登场过场（层开始前）

- 全屏暗色遮罩渐入（300ms）
- 中央显示 Boss SVG 剪影（占位）
- Boss 名字 + 称号从下方滑入
- 短暂停留 1.5 秒后淡出，战斗开始

**SVG 占位要求**：
```html
<!-- PLACEHOLDER: Boss 登场剪影
     位置：过场画面中央
     尺寸：200×280px
     内容：Boss 角色全身剪影（黑色轮廓 + 主题色光晕）
     替换方式：将下方 <svg> 替换为 <img src="assets/abyss/boss_{bossId}.svg">
     当前使用 SVG 矩形 + 文字占位 -->
```

#### 2b. 层通过过场（层结束后、下一层开始前）

- 显示 "✅ 第 X 层通过！" 横幅（slideUp 动画）
- 简要显示本层获得的奖励（金币/经验/装备图标）
- 1.5 秒后自动推进到下一层 Boss 登场

**验收标准**：

| # | 场景 | 预期 |
|---|------|------|
| B1 | 进入深渊第 1 层 | 显示华雄 Boss 登场过场（SVG 剪影 + 名字），1.5s 后开始战斗 |
| B2 | 击败第 1 层 Boss | 显示 "第 1 层通过" 横幅 + 本层奖励，然后切到第 2 层 Boss 登场 |
| B3 | 击败最终 Boss | 不显示 Boss 登场过场，直接进入通关结算 |
| B4 | 快速战斗模式 | 跳过所有过场画面 |
| B5 | 过场画面中玩家关闭面板 | 过场定时器清理，无泄漏 |

### FT-03：老虎机装备揭示特效

**目标**：品质 ≥ 3（稀有）的装备掉落时，用老虎机滚动特效替代翻牌，增强多巴胺刺激。

**触发条件**：

| 品质 | 效果 |
|------|------|
| ≤ 2（普通/优秀） | 文字列表展示（现有行为不变） |
| 3（稀有） | 单列老虎机快速滚动 + 蓝色闪光 |
| 4（史诗） | 单列老虎机 + 紫色全屏脉冲 |
| 5（传说） | 三列老虎机依次停止 + 金色光柱 + 全屏金色粒子 |
| 6（神话） | 三列老虎机 + 全屏红金闪烁 + 画面震动 + 延迟揭示 |

**老虎机动画机制**：

1. **容器**：全屏居中的"老虎机窗口"（SVG 边框占位），内含 1-3 列滚动条
2. **滚动内容**：各种装备图标（emoji 占位，后续替换为 SVG 装备图标）随机排列
3. **滚动行为**：
   - 初始高速滚动（200ms/格）
   - 逐渐减速（缓动函数）
   - 最终停在目标装备上
   - 多列时，从左到右依次停止（间隔 500ms）
4. **停止瞬间**：
   - 品质 3：蓝色闪光 + 轻微震动
   - 品质 4：紫色全屏脉冲 + 音效占位标记
   - 品质 5+：全屏庆祝特效（金色/红色粒子爆发）

**全屏特效（品质 ≥ 5）**：
- 叠加一个全屏半透明层
- 从中心向四周发射光线（CSS radial-gradient 动画）
- 金色粒子从停止的装备位置爆散
- 装备名称 + 品质以大字体居中显示
- 特效持续 2 秒后淡出

**SVG 占位要求**：
```html
<!-- PLACEHOLDER: 老虎机边框
     位置：结算界面居中
     尺寸：320×200px（单列时 120×200px）
     内容：古风卷轴/虎符造型的老虎机框架
     替换方式：将下方 <svg> 替换为 <img src="assets/abyss/slot-machine-frame.svg">
     当前使用 SVG 圆角矩形 + 纹理线条占位 -->

<!-- PLACEHOLDER: 装备图标（老虎机滚动项）
     位置：老虎机滚动列内
     尺寸：每项 60×60px
     内容：各类装备的简化图标
     替换方式：将 emoji 替换为 <img src="assets/equipment/icon_{type}.svg">
     当前使用 emoji 占位 (🗡️⚔️🛡️🏹💎) -->
```

**验收标准**：

| # | 场景 | 预期 |
|---|------|------|
| C1 | 掉落 1 件稀有(3)装备 | 单列老虎机滚动 → 停在装备上 → 蓝色闪光 |
| C2 | 掉落 1 件史诗(4)装备 | 单列老虎机 → 停止 → 紫色全屏脉冲 |
| C3 | 掉落 1 件传说(5)装备 | 三列老虎机依次停止 → 金色光柱 → 全屏金色粒子 |
| C4 | 掉落 1 件神话(6)装备 | 三列老虎机 → 全屏红金闪烁 → 画面震动 → 延迟停止 → 庆祝 |
| C5 | 同时掉落多件 quality ≥ 3 装备 | 依次播放老虎机（品质低→高），每件间隔 800ms |
| C6 | 仅掉落 quality ≤ 2 装备 | 跳过老虎机，直接文字展示 |
| C7 | 老虎机动画中点击「跳过」 | 立即停止滚动，直接显示结果 |
| C8 | prefers-reduced-motion 启用 | 跳过所有动画，直接显示装备结果 |

## 3. 非功能需求

| 维度 | 要求 |
|------|------|
| **性能** | 老虎机动画期间帧率 ≥ 30fps |
| **内存** | 动画结束后零残留 DOM 节点 |
| **SVG 占位** | 所有占位必须带 `<!-- PLACEHOLDER: ... -->` 注释说明替换方式 |
| **可替换性** | SVG 占位设计为易于后续替换为设计师素材 |
| **向后兼容** | 旧存档正常加载，新增 `instances[aid].firstCleared` 字段自动初始化 |

---

## 4. 不在范围内

- 音效系统（无音频基础设施）
- 新深渊副本内容
- 掉落概率调整
- Boss 技能 AI 改动
- Canvas 粒子（继续用 DOM + CSS）
