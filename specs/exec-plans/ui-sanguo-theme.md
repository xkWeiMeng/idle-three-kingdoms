# 执行计划：三国古风 UI 主题重塑

| 字段 | 值 |
|------|-----|
| **状态** | `Active` |

| **创建** | 2026-04-05 |

---

## 概览

将游戏 UI 从赛博朋克暗蓝风格转向三国古风墨色+朱红+鎏金主题。  
涉及 CSS 全局令牌替换、组件样式重构、JS 内联颜色更新、Canvas 绘制颜色同步。
