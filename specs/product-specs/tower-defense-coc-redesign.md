## 1. 概述与玩家价值

### 1.1 为什么做这个重制

当前塔防系统存在以下体验问题：
- **视觉简陋**：防御塔和敌人使用 emoji 表示（🏹🗡🐴），缺乏沉浸感
- **武将参与感不足**：武将仅提供被动 ATK 加成 + 每 10 秒一次隐形技能释放，玩家感受不到武将在战斗
- **时代设定违和**：从中世纪到现代科技（加特林、导弹、激光）与三国题材严重不匹配
- **敌人单调**：虽有 9 种敌人类型，但缺乏可视的攻城器械和技能表现
- **策略深度不足**：缺少类似 CoC 的基地布局规划感

### 1.2 核心玩家价值

> **让玩家体验"经营三国城池 + 指挥武将防守"的策略乐趣。**

- 🏯 **建造乐趣**：自由布局城墙、箭塔、陷阱，打造属于自己的三国城防
- ⚔ **武将战斗感**：招募的武将真正走上战场，释放可见的技能特效
- 👀 **视觉升级**：所有单位使用 SVG 渲染，技能用基本形状和线条展现
- 🧠 **策略深度**：不同敌人需要不同防御组合，攻城器械需要针对性应对

### 1.3 目标用户

已解锁城防系统的中期玩家（游戏 1.5h+），追求策略玩法和视觉满足感。

---

## 2. 设计原则

1. **完全三国化**：所有建筑、敌人、机制必须符合三国/古代中国设定，移除所有现代科技元素
2. **参考 CoC 核心循环**：建造防御 → 布局优化 → 迎击进攻 → 获取奖励 → 升级建筑
3. **武将是战场核心**：武将不再是被动光环，而是实际在地图上移动和战斗
4. **SVG 优先视觉**：使用 SVG 基本形状渲染所有单位和技能效果，保持轻量
5. **保持 Idle 本质**：自动防守仍为核心，手动操作提供额外奖励

## 3. 防御建筑体系（参考 CoC）

### 3.1 建筑分类

取消"4 个科技时代"设计，改为**建筑等级解锁制**（参考 CoC 的大本营等级解锁）。

#### 攻击型建筑

| 建筑 | 三国设定 | 功能描述 | SVG 概念 |
|------|---------|---------|---------|
| **箭塔** | 高台箭楼 | 单体远程攻击，射速快，攻击地面+空中 | 木质方塔 + 上方三角屋顶，攻击时顶部射出箭矢线条 |
| **弩车台** | 大型弩机平台 | 高伤害单体攻击，优先攻击高 HP 敌人 | 底座平台 + 十字形弩机 |
| **投石车台** | 抛石机阵地 | 范围溅射伤害，只攻击地面 | 三角支架 + 弧形投掷臂 |
| **烽火台** | 烽火信号塔 | 侦察塔，揭示隐蔽单位 + 范围内友军攻击加成 | 高塔 + 顶端火焰动画（闪烁的橙色圆形） |
| **火油塔** | 油锅台 | 范围持续灼烧伤害，攻击地面 | 大锅形状 + 溅落的火焰粒子 |
| **连弩塔** | 诸葛连弩台 | 高射速多目标攻击 | 旋转的多弩臂结构 |

#### 防御型建筑

| 建筑 | 三国设定 | 功能描述 | SVG 概念 |
|------|---------|---------|---------|
| **木栅栏** | 初级墙体 | 低 HP 墙体，阻挡和引导地面敌人 | 竖直木桩排列 |
| **城墙** | 石砖城墙 | 中 HP 墙体 | 灰色砖块矩形 |
| **铁壁** | 铁皮加固城墙 | 高 HP 墙体 | 深灰色矩形 + 铆钉圆点 |

#### 陷阱

| 建筑 | 三国设定 | 功能描述 | SVG 概念 |
|------|---------|---------|---------|
| **拒马** | 尖刺木桩 | 减速 + 伤害，一次性 | 交叉线条 |
| **陷坑** | 隐蔽坑洞 | 高伤害单体，一次性 | 虚线圆形（触发前隐蔽） |
| **火油池** | 地面油池 | 范围灼烧，可复用，有冷却 | 棕色/橙色椭圆 + 火焰闪烁 |
| **绊马索** | 绳索陷阱 | 使骑兵类目标停顿 2 秒 | 地面弧线 |

#### 城主府

城主府（大本营）等级决定所有建筑的解锁和数量上限，参考 CoC 大本营。

### 3.2 建筑视觉要求（SVG）

**核心原则**：使用 SVG 基本形状（rect、circle、line、polygon、path）绘制，不使用外部图片。

每个建筑需要：
1. **静态外观** — 放置在地图上的 SVG 图标（48×48 像素网格内）
2. **攻击动画** — 使用线条（line）或小圆形（circle）表示弹道
3. **等级标识** — 通过颜色/装饰数量区分等级

> 📐 数值需求标记：各建筑的 ATK、HP、射程、攻速、建造费用、升级费用曲线需要 `numerical-designer` 设计。

## 4. 敌人体系

### 4.1 兵种

取消现有的科幻向敌人（穿甲鼠、轰炸者等），全面替换为三国主题：

#### 地面兵种

| 兵种 | 设定 | 行为 | SVG 概念 |
|------|------|------|---------|
| **黄巾兵** | 农民起义军 | 基础步兵，数量多 HP 低 | 头裹黄巾的简笔人形 |
| **长枪兵** | 持长矛步兵 | 中等属性，均衡型 | 人形 + 长线条（枪） |
| **重甲兵** | 铁甲步卒 | 高 HP 高防，移速慢 | 宽体矩形身体 + 方盾 |
| **骑兵** | 轻骑突击 | 高速低防 | 人形 + 下方椭圆（马身），奔跑时有拖尾线 |
| **铁骑** | 重装骑兵 | 高 HP 高速，对墙体伤害 ×2 | 更大的骑兵形状 + 装甲线条 |

#### 攻城器械

| 器械 | 设定 | 行为 | SVG 概念 |
|------|------|------|---------|
| **攻城车** | 冲车 | 直线冲撞城墙，对墙体伤害 ×3，攻击城墙时播放撞击动画 | 长方形车体 + 前端尖头（三角形），车轮为底部圆形 |
| **云梯** | 登城梯 | 无视墙体直接翻越，速度中等 | 长梯形状（两竖线 + 多横线），靠近墙体时倾斜动画 |
| **投石车** | 远程攻城 | 在射程内停下攻击建筑（优先攻击防御建筑），高 ATK | 三角支架 + 弧形臂 + 投射弧线动画（虚线弧） |
| **冲城锤** | 最强攻城器 | 对城主府伤害 ×5，移速极慢 | 大型矩形框架 + 中间悬挂的圆形锤头 + 摆动动画 |

#### 特殊兵种

| 兵种 | 设定 | 行为 | SVG 概念 |
|------|------|------|---------|
| **刺客** | 隐蔽单位 | 需烽火台侦测，否则无法被攻击 | 半透明人形（虚线轮廓），被侦测后变实线 |
| **弓骑兵** | 远程骑兵 | 移动中对防御建筑射击 | 骑兵形状 + 斜线（弓箭轨迹） |
| **敌将** | 敌方武将 | 各波 Boss，有独特技能 | 较大的人形 + 头上旗帜（三角形），颜色区分不同敌将 |

### 4.2 敌人视觉要求（SVG）

每个敌人需要：
1. **行走外观** — 简笔 SVG 人形/器械形状
2. **攻击动画** — 武器挥砍（线条旋转）、弓箭射出（线段移动）
3. **HP 血条** — 头顶红色/绿色矩形条
4. **状态特效** — 减速（蓝色圆圈）、灼烧（橙色闪烁圆点）、中毒（绿色圆点）

> 📐 数值需求标记：各兵种的 HP/ATK/DEF 倍率、移速、出场波次配置需要 `numerical-designer` 设计。

## 5. 武将战斗系统（核心创新点）

### 5.1 玩家价值

> 已招募的武将不再是被动的 ATK 加成数字，而是实际出现在战场上战斗的角色。
> 玩家能看到自己培养的武将在城防中发挥作用，产生情感连接和培养动力。

### 5.2 武将部署

- 玩家最多可部署 **3 名武将**（从已招募且不在出征队伍的武将中选择）
- 武将部署到城防地图上的指定位置（玩家选择放置点）
- 武将有**巡逻范围**（以部署点为中心的圆形区域）

### 5.3 武将战斗行为

**基本行为**：
- 武将在巡逻范围内自动寻找最近的敌人移动并攻击
- 武将有独立的 HP 池（基于武将 baseHp + 等级成长）
- 武将 HP 归零时"撤退"（退出本波次战斗，非永久死亡），下波次自动复活满血
- 武将移速恒定为 2 格/秒（快于大部分敌人）

**技能释放**：
- 每个武将自带的技能按冷却时间自动释放（使用 heroes.js 中的 skill 定义）
- 技能释放时有**可见的特效**（基本形状/线条动画）

### 5.4 武将技能视觉

每个武将技能需要对应的 SVG 动画效果：

| 技能类型 | 视觉描述 | SVG 实现概念 |
|---------|---------|------------|
| **单体伤害**（如"锦囊快递"） | 从武将飞出投射物到敌人 | 小圆形沿直线移动 + 到达目标时放大消失 |
| **范围伤害**（如"天雷地火"） | 以目标为中心的扩散冲击波 | 扩大的圆环（circle，stroke-only，半径动画增长 → 消失） |
| **治疗**（如"仁义鸡汤"） | 绿色光环笼罩目标 | 绿色圆形从小到大 → 淡出 |
| **增益Buff**（如"白马银枪"） | 上升的光芒/箭头 | 向上移动的三角形 + 渐隐 |
| **减速/控制** | 蓝色冰霜/锁链效果 | 蓝色圆圈闪烁 + 短线条围绕目标旋转 |
| **穿透攻击** | 直线贯穿 | 粗线段从武将到远方快速延伸 → 消失 |

### 5.5 武将 SVG 外观

武将在城防地图上的 SVG 外观：
- 比普通兵种略大的人形（约 1.5× 普通兵种大小）
- 头顶显示武将名字（小字号文本）
- 身后有势力色彩的旗帜（蜀=绿、魏=蓝、吴=红、群=紫）
- 技能冷却用头顶小圆环进度条表示

> 📐 数值需求标记：武将在城防中的 HP 倍率、ATK 换算、技能冷却缩放、巡逻范围大小需要 `numerical-designer` 设计。

## 7. 用户故事

### US-01：布置城防

**作为**已解锁城防的玩家
**我想要**在城镇地图上自由放置箭塔、城墙等防御建筑
**以便于**构建自己的防御阵型

**验收标准**：
1. 玩家进入城防模式后，可从底部工具栏选择建筑类型
2. 点击地图空格即可放置，消耗对应资源
3. 所有建筑以 SVG 图形渲染（非 emoji）
4. 放置后不能完全封锁敌人路径（保持寻路通畅）
5. 长按已建造的建筑可升级或出售

### US-02：武将出战

**作为**拥有多个武将的玩家
**我想要**将我的武将部署到城防战场上
**以便于**看到他们实际参与战斗

**验收标准**：
1. 玩家可选择最多 3 名武将部署到地图上的指定位置
2. 武将以 SVG 人形渲染，头顶显示名字
3. 战斗开始后，武将在巡逻范围内自动寻敌攻击
4. 武将按冷却时间自动释放技能，技能有可见的 SVG 特效
5. 武将 HP 归零时"撤退"并在下波次复活

### US-03：抵御进攻

**作为**已布置防御的玩家
**我想要**观看敌人进攻我的城池
**以便于**体验策略防御的成就感

**验收标准**：
1. 敌人从地图边缘生成，以 SVG 渲染的单位形象显示
2. 各兵种有明显区分的外观（步兵、骑兵、攻城器械等）
3. 攻城器械有独特的攻击动画（攻城车撞墙、投石车抛射等）
4. 敌人受伤/死亡有视觉反馈（血条变化、消散动画）
5. 波次结算后显示奖励和下波预览

### US-04：应对攻城器械

**作为**面对高难度关卡的玩家
**我想要**看到攻城器械的独特表现
**以便于**知道该优先应对什么

**验收标准**：
1. 攻城车撞击城墙时有明显的撞击动画和伤害数字
2. 投石车在远处停下后有抛物线弹道动画
3. 云梯靠近城墙时有攀爬动画（直接翻越）
4. 冲城锤有锤头摆动的攻击动画
5. 各器械的体积明显大于普通兵种

### US-05：技能视觉体验

**作为**观看城防战斗的玩家
**我想要**看到武将和敌将释放技能时的炫酷效果
**以便于**获得视觉满足感

**验收标准**：
1. 武将释放单体伤害技能时，有投射物从武将飞向目标
2. 范围技能有以目标为中心的扩散圆环效果
3. 治疗技能有绿色光环效果
4. Boss 技能有独特的大范围特效
5. 所有特效使用基本 SVG 形状（circle、line、rect、path）实现

### US-06：防御建筑攻击动画

**作为**玩家
**我想要**看到防御建筑攻击敌人时的弹道和效果
**以便于**直观了解我的防御在发挥作用

**验收标准**：
1. 箭塔攻击时有箭矢线条从塔飞向目标
2. 投石车台有抛物线弹道（虚线弧 + 落点圆形爆炸）
3. 火油塔有向下泼洒的橙色区域效果
4. 连弩塔有多条快速射出的线段
5. 弹道速度合理，不是瞬间命中而是有飞行过程

## 9. SVG 渲染系统需求

### 9.1 架构概述

需要新建一个 **TD SVG 渲染引擎**，在 Canvas 上使用代码绘制 SVG 风格图形（因为游戏使用 Canvas 渲染）。

实际实现方式：在现有 Canvas 上使用 Canvas 2D API 绘制"SVG 风格"图形（使用 path、arc、线条等基本绘图指令）。

### 9.2 渲染层级

从底到顶的渲染顺序：
1. 地形层（TownWorld 已有）
2. 建筑层（城墙、防御建筑）
3. 陷阱层（半透明，战斗中完全隐藏直到触发）
4. 地面单位层（敌人步兵、骑兵、攻城器械）
5. 武将层（我方武将，略大于普通单位）
6. 弹道层（箭矢、石弹轨迹）
7. 特效层（技能动画、爆炸、状态效果）
8. UI 层（血条、名字、冷却条）

### 9.3 SVG 图形设计规范

**通用规则**：
- 所有单位图形在 48×48 像素网格内绘制
- 使用有限的色板（三国风：红、金、棕、灰、绿）
- 线宽统一：轮廓 2px，细节 1px
- 动画使用 Canvas API 逐帧渲染（不使用 CSS animation）

**建筑图形示例**：
```
箭塔（Arrow Tower）:
- 底座: rect(12,28,24,18) 填充 #8B6914
- 塔身: rect(16,10,16,22) 填充 #A07828
- 屋顶: polygon(14,12  24,2  34,12) 填充 #C41E3A
- 窗口: rect(20,16,8,6) 填充 #1a1a2e

攻击动画: line(24,12 → 目标位置) 颜色 #FFD700 线宽2
```

**敌人图形示例**：
```
步兵（Infantry）:
- 头: circle(24,10,6) 填充 #DEB887
- 头巾: arc(24,10,7, π, 2π) 填充 #DAA520
- 身体: rect(18,16,12,14) 填充 #B8860B
- 腿: 两条短线 line(20,30→18,38) line(28,30→30,38)
- 武器: line(32,12→36,28) #808080

攻城车（Siege Ram）:
- 车体: rect(6,16,36,20) 填充 #654321
- 车轮: circle(14,38,6) circle(34,38,6) 描边 #444
- 撞头: polygon(42,20 48,26 42,32) 填充 #808080
- 顶棚: rect(8,10,32,8) 填充 #8B4513

撞击动画: 车体水平抖动 ±3px × 3次 + 墙体位置圆形冲击波
```

## 11. 成功指标（KPI）

| 指标 | 目标 | 衡量方式 |
|------|------|---------|
| 视觉辨识度 | 所有建筑/敌人可通过外观区分 | 玩家看到单位能说出类型 |
| 武将存在感 | 武将在战场上可见移动和攻击 | 武将有完整的移动+攻击+技能动画 |
| 技能反馈 | 技能释放有清晰的视觉效果 | 每个技能有独立的动画特效 |
| 策略深度 | 不同关卡需要不同阵型 | 存在至少 3 种有效的防御策略 |
| 渲染性能 | ≥ 30 FPS | 50 个活跃实体同屏时帧率达标 |

## 12. 数值需求摘要（需 numerical-designer 深化）

以下部分需要 `numerical-designer` 提供详细数值规范：

1. **防御建筑数值表**：各建筑的 ATK、HP、射程、攻速、建造费用、升级费用曲线
2. **敌人数值表**：各兵种的 HP/ATK/DEF 倍率、移速
3. **攻城器械数值**：对墙体/建筑的伤害倍率
4. **武将城防参数**：HP 池计算公式、ATK 换算、技能冷却缩放、巡逻范围
5. **波次配置**：各章节各关卡的兵种组合和数量
6. **奖励曲线**：与当前系统的经济平衡对比
7. **城主府等级解锁表**：各等级解锁的建筑类型和数量上限
