## 1. 概述与玩家价值

### 1.1 为什么做弹珠

当前游戏缺少有效的**玉璧消耗渠道**。玉璧作为高级货币主要通过招募消耗，但中后期玩家积累速度远超消耗速度，导致货币膨胀。弹珠系统通过博弈机制（高风险高回报）提供一个有趣的玉璧出口，同时给予玩家获得稀有装备的额外途径。

### 1.2 核心玩家价值

> **用 10 玉璧的小赌注换取一次刺激的弹珠弹射体验，享受碰撞的随机性和中大奖的爽感。**

- 🎰 **博弈快感**：每颗弹珠都可能中超级大奖（500 玉璧 + 神话装备）
- 🎮 **物理趣味**：Canvas 真实物理模拟，弹珠碰撞钉子的路径每次不同
- ⚖️ **风险决策**：玩家自主决定何时停手，无次数限制
- 💎 **装备来源**：提供另一条获得传说/史诗/神话装备的路径

### 1.3 目标用户

所有玩家。无需解锁，直接可用。主要面向有玉璧积累的中后期玩家。

---

## 2. 设计原则

1. **公平透明**：奖槽分布和概率由物理布局决定，玩家可直观观察
2. **净消耗定位**：理论期望回报率 60~70%，确保玉璧的长期净流出
3. **即时反馈**：弹珠碰撞和落槽的视觉反馈要即时且清晰
4. **无强制**：纯可选内容，不影响主线进度

## 3. 能力定义

### CAP-PCK-01: 弹珠发射

**描述**：玩家消耗 10 玉璧发射一颗弹珠。

**前置条件**：
- 玩家拥有 ≥10 玉璧
- 当前无弹珠正在飞行

**行为**：
- 点击"发射"按钮，立即扣除 10 玉璧
- 弹珠从顶部发射口射出，带有微小随机角度偏移
- `resource:changed` 事件触发

**WHEN/THEN**：

```
WHEN 玩家点击发射按钮且玉璧 ≥ 10
THEN 扣除 10 玉璧，弹珠从顶部发射
AND resource:changed('jade', newAmount) 触发

WHEN 玩家点击发射按钮且玉璧 < 10
THEN 显示 toast 提示"玉璧不足"
AND 不发射弹珠

WHEN 弹珠正在飞行中且玩家点击发射
THEN 忽略点击（一次只能一颗弹珠）
```

### CAP-PCK-02: 物理模拟

**描述**：Canvas 2D 物理引擎模拟弹珠弹射。

**物理参数**：
- 重力加速度：500 px/s²
- 弹性系数（弹珠-钉子）：0.5
- 弹性系数（弹珠-墙壁）：0.6
- 弹珠半径：6px
- 钉子半径：4px
- 摩擦系数：0.99（速度衰减）

**钉子阵列**：
- 交错排列（奇数行偏移半列）
- 8~10 行，每行 9~11 颗钉子
- 行间距 35px，列间距 30px

**守护钉（命釘）**：
- 大奖槽上方设置 5 颗守护钉，形成窄漏斗结构
- 中央分流钉（半径 7px）：拨开直落的弹珠
- 外层漏斗（2 颗，半径 6px）：引导弹珠向外偏转
- 内层守护（2 颗，半径 6px）：极窄入口，间隙仅略大于弹珠直径
- 守护钉渲染为红铜色，与普通钉子视觉区分

**行为**：
- 弹珠受重力加速下落
- 碰到钉子时弹性反弹 + 微小随机扰动
- 碰到左右墙壁时反弹
- 最终落入底部 9 个奖槽之一

**WHEN/THEN**：

```
WHEN 弹珠碰到钉子
THEN 按弹性系数反弹，加入 ±5° 随机扰动
AND 钉子播放碰撞动画（短暂变色/缩放）

WHEN 弹珠碰到左右边界
THEN 水平速度反转 × 弹性系数

WHEN 弹珠 Y 坐标进入奖槽区域
THEN 判定落入的奖槽
AND 触发结算流程 (CAP-PCK-03)

WHEN 弹珠超过 15 秒仍未落槽（防卡死）
THEN 强制结算到最近的奖槽
```

### CAP-PCK-03: 奖槽结算

**描述**：弹珠落入奖槽后发放奖励。

**奖槽布局（从左到右 9 个）**：

| 位置 | 类型 | 玉璧奖励 | 装备奖励 | 颜色 |
|------|------|----------|----------|------|
| 1 | 空奖 | 0 | 无 | 灰色 |
| 2 | 小奖 | 5~15 | 无 | 绿色 |
| 3 | 中奖 | 30~50 | 无 | 蓝色 |
| 4 | 空奖 | 0 | 无 | 灰色 |
| 5 | 超级大奖 | 500 | Q4(70%)/Q5(20%)/Q6(10%) | 金色闪烁 |
| 6 | 空奖 | 0 | 无 | 灰色 |
| 7 | 中奖 | 30~50 | 无 | 蓝色 |
| 8 | 小奖 | 5~15 | 无 | 绿色 |
| 9 | 大奖 | 100~200 | 50%概率Q3装备 | 紫色 |

**WHEN/THEN**：

```
WHEN 弹珠落入空奖槽
THEN 显示"未中奖"提示
AND 无任何奖励

WHEN 弹珠落入小奖槽
THEN 返还 5~15 玉璧（随机）
AND 显示绿色奖励文字
AND resource:changed 触发

WHEN 弹珠落入中奖槽
THEN 返还 30~50 玉璧（随机）
AND 显示蓝色奖励文字

WHEN 弹珠落入大奖槽
THEN 返还 100~200 玉璧（随机）
AND 50% 概率获得一件 Q3(稀有) 装备
AND 显示紫色奖励文字 + 特效

WHEN 弹珠落入超级大奖槽
THEN 返还 500 玉璧
AND 获得一件装备：70% Q4(史诗) / 20% Q5(传说) / 10% Q6(神话)
AND 播放全屏庆祝特效（CelebrationOverlay）
AND pachinko:jackpot 事件触发
```

### CAP-PCK-04: 统计与历史

**描述**：记录弹珠游戏的统计数据和最近历史。

**状态**：
- `totalPlays`：总发射次数
- `totalSpent`：总花费玉璧
- `totalWon`：总赢得玉璧
- `jackpotCount`：超级大奖次数
- `history`：最近 20 条记录

**WHEN/THEN**：

```
WHEN 每次弹珠结算完成
THEN totalPlays++, totalSpent += 10, totalWon += 奖励玉璧
AND history 头部插入本次记录
AND 若 history 长度 > 20 则裁剪

WHEN 中超级大奖
THEN jackpotCount++
```

### CAP-PCK-05: 面板 UI

**描述**：通过 OverlayPanel 展示弹珠面板。

**布局**：
- 顶部：玉璧余额 + 发射按钮（大按钮，显眼）
- 中部：Canvas 弹珠机（占面板主体）
- 底部：统计面板（总局数/总花费/总赢取/净盈亏/大奖次数）
- 可展开：历史记录列表

**WHEN/THEN**：

```
WHEN 玩家从 BottomNav 更多菜单点击"弹珠"
THEN 打开 OverlayPanel（height: 'full'）
AND 渲染弹珠面板

WHEN 面板关闭
THEN 停止 Canvas 动画循环（节省性能）

WHEN 面板重新打开
THEN 恢复 Canvas 渲染
AND 从 PachinkoManager 读取最新统计数据
```

## 6. 数值平衡

### 期望值计算

假设物理布局（含守护钉漏斗）导致以下大致概率分布：

| 奖项 | 概率 | 平均奖励(玉璧) | 贡献 EV |
|------|------|----------------|---------|
| 空奖 | 50% | 0 | 0 |
| 小奖 | 24% | 10 | 2.4 |
| 中奖 | 16% | 40 | 6.4 |
| 大奖 | 8% | 150 | 12.0 |
| 超级大奖 | 2% | 500 | 10.0 |
| **合计** | 100% | — | **30.8** |

装备奖励不计入玉璧 EV。纯玉璧回报率 ≈ 30.8/10 × 100% ≈ **31%**。  
加上装备价值（可出售），总体感知回报率约 **50~60%**。守护钉有效压低了大奖命中率。

> 可通过调整钉子间距和奖槽宽度微调概率分布。
