## 1. 概述

城防塔防系统是一个在现有城镇地图上运行的波次制防御子系统。敌军从地图四条边缘生成，沿路径向城主府推进；玩家在网格上布置防御建筑拦截敌军。防御科技从中世纪演进到现代科技，横跨 4 个时代。系统保持 Idle 特性——自动防守持续运转，手动操作提供额外收益加成。

**核心定位**：中期解锁的资源获取 + 策略玩法通道，与武将系统联动，丰富城镇地图的交互维度。

## 2. 术语表

| 术语 | 定义 |
|------|------|
| **防御塔（Tower）** | 放置在城镇网格上的防御建筑，自动攻击射程内的敌人 |
| **墙体（Wall）** | 阻挡地面/地下敌人的障碍物，拥有 HP，被攻击可摧毁 |
| **陷阱（Trap）** | 地面触发式装置，敌人经过时激活，多为一次性 |
| **波次（Wave）** | 一轮敌人进攻，所有敌人消灭或攻破城主府后结束 |
| **时代（Era）** | 科技等级，决定可建造的防御建筑类型 |
| **探测（Detection）** | 使隐蔽的地下敌人对远程塔可见的能力 |
| **DPS** | 每秒伤害（Damage Per Second） |
| **寻路（Pathfinding）** | 敌人从生成点到城主府的 A\* 路径计算 |
| **防守模式（Defense Mode）** | TD 专用游戏模式，激活后城镇地图切换为战场视图 |

## 3. 解锁条件

### 3.1 精确触发条件

| 条件 | 要求 | 说明 |
|------|------|------|
| 关卡进度 | 通关 `stage_2_10`（第 20 关） | 第二章完成 |
| 城主府等级 | ≥ 3 | 确保有足够建筑空间 |

两个条件必须**同时满足**。

### 3.2 解锁时间估算

| 指标 | 1.5h 时预期值 | 说明 |
|------|--------------|------|
| 关卡进度 | 20-25 关 | 自动推图，每关约 15-25 秒 |
| 城主府等级 | 3-4 级 | Lv3 费用：1,620金+324木+324石+50铁（costFormula(3)） |
| 武将数量 | 3-5 个 | 含免费招募和首通奖励 |
| 武将等级 | 15-20 级 | 自动获取经验 |
| 累计金币 | ~15,000-20,000 | 初期 ~6,000/h，含战斗奖励 |
| 累计木材 | ~2,000-3,000 | 伐木场 Lv1 起步 2/min |

### 3.3 解锁反馈

WHEN 玩家同时满足 `stage_2_10` 通关 AND 城主府 ≥ 3
THEN 触发 `td:unlocked` 事件
AND 弹出 Toast（type: 'success', message: '城防系统已解锁！'）
AND 底部导航「城镇」页签显示红点
AND 城镇地图出现「城防」入口按钮

WHEN 玩家通关 `stage_2_10` 但城主府 < 3
THEN 不触发解锁
AND 城镇面板提示「升级城主府至 3 级解锁城防」

## 4. 能力

### CAP-TD-01：进入防守模式

WHEN 城防已解锁且玩家点击「城防」按钮
THEN 城镇地图切换为防守模式视图
AND 显示波次信息面板（当前波/最高波）
AND 显示可放置塔位的空格高亮
AND 显示底部塔建造工具栏

WHEN 玩家在防守模式中无活跃波次时点击「返回」
THEN 退出防守模式，恢复正常城镇视图

WHEN 有活跃波次时点击「返回」
THEN 显示确认对话框「战斗进行中，离开将切换为自动防守，确定离开？」

### CAP-TD-02：建造防御塔

WHEN 玩家从工具栏选择塔类型并点击空闲网格
AND 该塔类型已通过科技研究解锁
AND 资源足够支付建造费用
THEN 消耗资源，在该格放置塔实例（uid = Utils.uid()）
AND 触发 `td:tower_built` 事件
AND 重新计算敌人寻路路径

WHEN 资源不足
THEN 建造按钮灰显，提示「资源不足：缺少 X 金 / Y 木」

WHEN 目标网格已被建筑/塔/道路占用
THEN 提示「无法放置：该位置已占用」

WHEN 放置塔后导致敌人无法到达城主府（完全封路）
THEN 阻止放置，提示「无法放置：不能完全封锁敌人路径」

### CAP-TD-03：升级防御塔

WHEN 玩家点击已建造的塔且等级 < 5
AND 资源足够支付升级费用
THEN 消耗资源，塔等级 +1，属性按升级公式提升
AND 触发 `td:tower_upgraded` 事件

WHEN 塔已达最大等级（5级）
THEN 升级按钮灰显，显示「已满级」

WHEN 资源不足
THEN 升级按钮灰显，显示差额

### CAP-TD-04：出售防御塔

WHEN 玩家长按已建造的塔并确认出售
AND 当前无活跃波次
THEN 移除塔实例，返还建造费用的 50%（向下取整）
AND 触发 `td:tower_sold` 事件
AND 重新计算寻路

WHEN 活跃波次进行中出售
THEN 返还率降为 30%

### CAP-TD-05：启动波次

WHEN 玩家点击「开始波次」按钮且当前无活跃波次
THEN 进入 15 秒准备倒计时
AND 显示下一波敌人预览（类型、数量）

WHEN 倒计时结束或玩家点击「跳过准备」
THEN 从地图四边随机选取 1-2 个生成点
AND 按波次表生成敌人，敌人开始向城主府移动
AND 触发 `td:wave_started` 事件

WHEN 玩家首次进入防守模式
THEN 自动从第 1 波开始

WHEN 玩家已完成第 N 波
THEN 下次进入从第 N+1 波开始

### CAP-TD-06：敌人行为

WHEN 敌人生成后
THEN 以 A\* 算法计算到城主府的最短路径（考虑建筑和墙体为障碍物）
AND 按自身移速沿路径移动

WHEN 地面/地下敌人路径上有墙体
THEN 停下攻击墙体（DPS = 敌人 ATK × (1 - 墙体 DEF/(墙体 DEF+100))）

WHEN 墙体 HP 归零
THEN 墙体摧毁，敌人重新寻路

WHEN 敌人到达城主府
THEN 城主府 HP 减少（减少值 = 敌人当前 HP 的 10% + 敌人 ATK）
AND 该敌人消失

WHEN 城主府 HP 归零
THEN 波次失败，触发 `td:wave_failed` 事件
AND 保留已清除波次的奖励
AND 城主府 HP 恢复至满，弹幕结束

WHEN 空中敌人移动
THEN 直线飞向城主府，无视地面障碍物

WHEN 地下敌人移动
THEN 沿地面路径移动但远程塔无法瞄准（除非被探测）

### CAP-TD-07：塔攻击逻辑

WHEN 敌人进入塔的射程内
AND 该敌人类型属于塔的可攻击目标
THEN 塔按攻速间隔自动攻击最近的可攻击敌人

WHEN 塔攻击敌人
THEN 造成伤害 = 塔 ATK × (1 − 敌人 DEF / (敌人 DEF + 100))

WHEN 敌人 HP ≤ 0
THEN 敌人死亡，从战场移除
AND 触发 `td:enemy_killed` 事件

WHEN 陷阱类防御被地面敌人踩踏
THEN 立即触发陷阱效果（伤害/减速），一次性陷阱消耗后消失

WHEN 塔射程内有多个可攻击敌人
THEN 优先攻击最接近城主府的敌人（路径距离最短者）

### CAP-TD-08：波次结算

WHEN 波次中所有敌人被消灭且城主府 HP > 0
THEN 波次通关，发放奖励
AND 触发 `td:wave_cleared` 事件
AND `wave.current += 1`；更新 `wave.highest = max(highest, current)`
AND 进入 15 秒准备阶段等待下一波

WHEN 波次通关时玩家处于手动操作模式
THEN 奖励倍率 = 1.3（金币 +30%，经验 +20%）

WHEN 波次通关时为自动防守
THEN 奖励倍率 = 1.0（正常奖励）

### CAP-TD-09：自动防守

WHEN 玩家离开防守模式或退出游戏且有已放置的塔
THEN 系统每次 `game:tick` 模拟简化版防守
AND 按当前阵型对当前波次做胜率判定

WHEN 简化防守胜率 ≥ 80%
THEN 自动通关该波次，发放 70% 基础奖励，推进到下一波

WHEN 简化防守胜率 < 80%
THEN 停留在当前波次，不自动推进

**简化胜率公式**：  
`winRate = min(1.0, totalTowerDPS × waveDuration / totalEnemyHP)`  
其中 `totalTowerDPS` = 所有塔的 DPS 之和；`waveDuration` = 60 秒假设值；`totalEnemyHP` = 波次所有敌人 HP 之和。

### CAP-TD-10：武将派驻

WHEN 玩家在防守模式的「武将」面板中选择武将并分配到防守位
AND 该武将不在出征队伍中（与 BattleManager 队伍互斥）
AND 防守位未满（最多 2 名）
THEN 武将加入防守阵容，提供防御光环加成
AND 触发 `td:hero_assigned` 事件

WHEN 派驻武将数已达 2 名
THEN 新武将替换最后一名，确认对话框提示

**武将防御光环**：
- 全场塔 ATK 加成 = +1% × floor(武将 ATK / 10)
- 武将技能每 10 秒自动释放一次，对随机敌人造成 `武将ATK × 技能倍率 × 0.5` 伤害

WHEN 派驻武将等级 20，ATK = 150（含装备）
THEN 塔 ATK 加成 = +15%
AND 技能 DPS ≈ 150 × 1.8 × 0.5 / 10 = 13.5（以诸葛亮为例）

### CAP-TD-11：科技研究

WHEN 玩家在科技面板选择下一时代研究项目
AND 满足前置条件（上一时代已解锁 + 资源足够）
THEN 消耗资源，开始研究倒计时
AND 触发 `td:research_started` 事件

WHEN 研究计时完成（受 game:tick 驱动）
THEN 解锁该时代所有建筑类型
AND 触发 `td:era_unlocked` 事件
AND Toast 提示「[时代名] 科技解锁！」

WHEN 研究进行中玩家离线
THEN 上线后检查时间差，若已超过研究时长则立即完成

### CAP-TD-12：城主府防御 HP

城主府在防守模式中拥有独立 HP 池，不影响正常建筑功能。

**城主府防御 HP** = 500 + 城主府等级 × 200

WHEN 进入新一轮防守（从波次 1 开始）
THEN 城主府 HP 恢复至满

WHEN 城主府 HP 归零
THEN 当前波次失败，停止出怪
AND 已通过的波次奖励保留
AND 城主府 HP 恢复至满，下次从失败波次重新开始

## 5. 数据结构

### 5.1 存档格式（TowerDefenseManager.getState()）

```json
{
  "unlocked": false,
  "era": 1,
  "research": {
    "era_2": { "completed": false, "startTime": null },
    "era_3": { "completed": false, "startTime": null },
    "era_4": { "completed": false, "startTime": null }
  },
  "towers": [
    {
      "uid": "string — Utils.uid()",
      "type": "string — TowerData.id",
      "level": "number — 1-5",
      "gridX": "number — 网格列",
      "gridY": "number — 网格行"
    }
  ],
  "wave": {
    "current": 1,
    "highest": 0,
    "townHallHp": 1100,
    "townHallMaxHp": 1100
  },
  "assignedHeroes": ["string — hero uid, max 2"],
  "stats": {
    "totalWavesCleared": 0,
    "totalKills": 0,
    "totalGoldEarned": 0
  },
  "tutorialSeen": false
}
```

**规则**：
- `towers` 数组最大长度 = `8 + 城主府等级 × 3`
- `assignedHeroes` 中的 uid 必须在 HeroManager 中存在且不在 BattleManager 出征队伍中
- `era` 值范围 [1, 4]，只增不减
- `wave.current` ≥ 1，`wave.highest` ≥ 0
- 活跃波次的敌人状态不持久化；离线时使用简化防守判定

### 5.2 塔实例运行时状态（非持久化）

### 6.2 塔升级公式

塔可升级 1-5 级，属性线性增长：

| 等级 | 属性倍率 | 墙体 HP 倍率 | 升级费用（基于建造费） |
|------|---------|------------|---------------------|
| 1 | ×1.00 | ×1.00 | — |
| 2 | ×1.20 | ×1.30 | 建造费 × 1.0 |
| 3 | ×1.40 | ×1.60 | 建造费 × 1.5 |
| 4 | ×1.60 | ×2.00 | 建造费 × 2.0 |
| 5 | ×2.00 | ×2.50 | 建造费 × 3.0 |

**公式**：
- 升级后 ATK = baseATK × 属性倍率
- 升级后墙体 HP = baseHP × HP倍率
- 射程和攻速不随等级变化

## 7. 数值设计

### 7.1 波次基础属性公式

每波敌人的基础属性由波次编号 `n` 决定，再乘以敌人类型倍率：

| 属性 | 公式 | 说明 |
|------|------|------|
| HP(n) | `floor(100 × 1.12^(n-1) × (1 + 0.03 × max(0, n-10)))` | 12%/波指数增长 + 第 10 波后额外 3%/波线性加速 |
| ATK(n) | `floor(15 × 1.08^(n-1))` | 8%/波指数增长 |
| DEF(n) | `floor(8 × 1.06^(n-1))` | 6%/波指数增长 |
| 出怪数(n) | `3 + floor((n-1) / 4)` | 每 4 波多 1 个敌人（Boss 波除外） |

**Boss 波（每 5 波）规则**：
- 出怪数 = 1（单个 Boss），波次 20 例外：1 Boss + 4 随从
- Boss HP = 基础 HP(n) × 3
- Boss ATK = 基础 ATK(n) × 2
- Boss DEF = 基础 DEF(n) × 2

**倍率叠加规则**：Boss 倍率**替代**敌人类型的 HP/ATK/DEF 倍率（即 Boss 不再额外乘类型倍率），但保留类型的移速和特殊能力。非 Boss 普通敌人的实际属性 = 基础属性(n) × 敌人类型倍率。

### 7.3 伤害公式

与现有战斗系统统一：

```
伤害 = ATK × (1 − DEF / (DEF + 100))
```

**塔 DPS 计算示例**：
- 箭塔 Lv1（ATK 20）vs 步兵波次 1（DEF 8）：伤害 = 20 × (1 - 8/108) = 18.5/击，DPS = 18.5
- 箭塔 Lv1 vs 步兵波次 10（DEF 13）：伤害 = 20 × (1 - 13/113) = 17.7/击，DPS = 17.7
- 火炮塔 Lv1（ATK 60）vs 重步兵波次 10（DEF 13×2=26）：伤害 = 60 × (1 - 26/126) = 47.6/击，DPS = 15.7

### 11.1 TD 战斗 Tick 架构

全局 `game:tick`（1 秒间隔）不适用于实时 TD 战斗（加特林塔攻速 3.0 次/秒、敌人需平滑移动）。TD 系统采用**双频率架构**：

| 循环 | 频率 | 驱动内容 | 运行条件 |
|------|------|---------|---------|
| `game:tick` | 1 Hz | 科技研究倒计时、自动防守判定、解锁检查 | 始终运行 |
| TD 战斗循环 | `requestAnimationFrame`（~60 Hz） | 敌人移动、塔攻击、弹道渲染、碰撞检测、陷阱触发 | 仅防守模式且有活跃波次时运行 |

**TD 战斗循环实现**：
- 使用 `requestAnimationFrame` 驱动，通过 `deltaTime` 计算实际经过时间
- 逻辑更新按 `deltaTime` 缩放：`enemy.x += enemy.speed * TILE_SIZE * dt`
- 塔攻击计时：`timeSinceLastAttack += dt`，当 `>= 1/attackSpeed` 时触发攻击
- 渲染与逻辑在同一帧内完成（CPU 开销低，无需分离）
- 退出防守模式时停止 rAF 循环，恢复为 `game:tick` 驱动的自动防守

**与 TownWorld 的关系**：
- 防守模式复用 TownWorld 的 Canvas 元素和摄像机系统
- 叠加渲染 TD 图层（敌人、弹道、射程指示器）
- 退出防守模式时移除 TD 图层，恢复正常城镇渲染

### 11.2 存档恢复行为

WHEN 玩家读取存档且上次处于波次进行中
THEN 回退到该波次起始状态（塔布局和波次编号保留，敌人重新生成）
AND 城主府 HP 恢复至该波次开始时的值（= `townHallMaxHp`）

WHEN 玩家读取存档且上次不在波次中
THEN 正常恢复 TD 状态，从 `wave.current` 继续

### 11.3 新手引导

WHEN 玩家首次进入防守模式（`tutorialSeen === false`）
THEN 显示简易引导弹窗，分 3 步：
1. 「在空格上点击放置箭塔 🏹」（高亮工具栏箭塔按钮）
2. 「敌人将从地图边缘进攻，防守城主府！」（高亮城主府位置）
3. 「点击"开始波次"迎战！」（高亮开始按钮）
AND 引导完成后自动标记 `tutorialSeen: true`（存档中）
